# Руководство пользователя

**Instron Lab** — программа для пакетной обработки результатов испытаний
на одноосное растяжение (экспорт сырых данных Instron 3365).

Приложение считает по методичке: деформацию ε, напряжение σ, предел
прочности σ_max, касательный и секущие модули Юнга, среднее и СКО по серии
образцов. Строит графики, позволяет вручную скорректировать обрезку данных
и линейный участок, выгружает таблицы (CSV/XLSX) и графики (SVG/PNG/ZIP)
для публикаций.

---

## 1. Запуск

| Способ | Действие |
|---|---|
| Windows | Двойной клик по `instron-lab.exe` — откроется окно приложения |
| Linux | `./instron-lab` |
| Запасной вариант | Открыть файл `index.html` (single-file) в любом браузере |

Лаунчер сам закрывается примерно через минуту после закрытия окна
приложения. Если окно не открылось — программа напечатает адрес вида
`http://127.0.0.1:XXXXX/`, откройте его в браузере вручную.

## 2. Загрузка данных

Программа принимает **папки** `*.is_tens_RawData` целиком и/или
**отдельные файлы** `Specimen_RawData_N.csv`:

- перетащите папку или файлы в окно (drag & drop);
- либо нажмите «Выбрать папку» / «Выбрать файлы».

Повторные загрузки **добавляют** образцы в общий список — можно собрать
несколько серий в один батч.

Если рядом с папкой RawData лежит файл `*.is_tens_Results.csv` — загрузите
его вместе с остальными, и метки образцов подставятся автоматически.

Файл, который не удалось разобрать, не мешает остальным: он появится
в таблице строкой с пометкой об ошибке.

Кнопка **✕** в правом верхнем островке очищает всё.

## 3. Таблица результатов (нижняя панель)

Каждая строка — образец:

- **✓** — включён/исключён из обработки;
- **Метка** — редактируемое имя образца (кликните и печатайте);
- **Файл** — имя исходного файла;
- геометрия: l₀, b₀, h_ср;
- расчётные величины: N_max, σ_max, ε_max, ε@σ_max, E_тан, E_сек1, E_сек2;
- мини-график σ(ε) — быстрый взгляд на форму кривой.

Внизу — строки статистики по **активным** образцам: Среднее, СКО
(по формуле методички — деление на n) и X̄ ± 2σ.

**Сортировка** — клик по заголовку колонки; порядок синхронизирован
с разделом графиков. Повторный клик меняет направление.

**Исключение образца** — снимите галочку в таблице или в заголовке
секции графиков: образец мгновенно выпадает из статистики, сводных
графиков и экспорта, но остаётся в списке и восстановим одним кликом.

**Клик по строке** — прокрутка к графикам этого образца с подсветкой.

Высота панелей регулируется перетаскиванием разделителя.

## 4. Графики

Для каждого активного образца — 4 графика:

1. **N(Δl) исходная** — красным показаны отрезанные начало и хвост;
2. **N(Δl) после обрезки** и сдвига в начало координат;
3. **σ(ε)** — диаграмма растяжения;
4. **σ(ε) с аппроксимацией** — красная пунктирная прямая, зелёные секущие
   из начала координат, маркеры границ линейного участка, зелёная зона.

Внизу — два **сводных** графика (наложение всех активных образцов):
N(Δl) и σ(ε).

### Подробный просмотр

**Клик по миниатюре** (или кнопка **⤢**) — график на весь экран.
В нём работают: зум колёсиком мыши, панорама (drag), тулбар Plotly,
кнопки выгрузки SVG/PNG/копирование в буфер. **Esc** или **✕** — назад.

### Редактирование границ обрезки (график 1)

Откройте график 1 — редактор запустится сразу (или кнопка **✎**
в шапке карточки):

- **Перетаскивайте янтарные ручки** — левая задаёт начало данных,
  правая — конец (обрезка хвоста);
- либо введите границы числом в поля **Δl, мм** (Enter или клик в сторону
  применяет);
- под графиком — предпросмотр: σ_max, ε_max и число оставшихся точек;
- **Авто** — вернуть автоматическую обрезку.

Изменения применяются сразу: пересчитываются вся кривая, все модули,
статистика и сводные графики. Образец помечается значком **✎ обрезка**
и колонкой «Правка» в экспорте.

### Редактирование линейного участка (график 4)

Откройте график 4 — аналогично:

- **ручки** задают границы участка по ε (можно тянуть и за пределы пика —
  для особых случаев, по умолчанию участок ищется до σ_max);
- поля **ε, %** — точный ввод;
- предпросмотр показывает E_тан и R² в реальном времени;
- **Авто** — вернуть автопоиск участка.

Ячейка E_тан в таблице помечается **✎**, в экспорт добавляется отметка
«участок вручную».

## 5. Параметры расчёта (кнопка ⚙)

- **Порог начала** (trimK, доля N_max) — отсекает мёртвую зону в начале
  записи. По умолчанию 0.005.
- **Порог хвоста** (tailK) — отсекает «пустой» хвост после разрыва,
  пока сила ниже доли от пиковой. По умолчанию 0.25.
- **R² участка** (r2Min) — минимальный R² авто-найденного линейного
  участка. По умолчанию 0.99.
- **Мин. окно** (winFrac) — минимальная доля точек участка. По умолчанию 0.1.

Изменение параметра мгновенно пересчитывает все образцы
(кроме тех, где границы заданы вручную — они не трогаются).

## 6. Экспорт

### Таблицы — кнопка «Экспорт…»

| Опция | Содержимое |
|---|---|
| Формат | **XLSX** или **CSV** (UTF-8, разделитель «;» — открывается в Excel) |
| Итоговая таблица | все активные образцы + строки статистики + параметры расчёта |
| Таблицы по образцам | в XLSX — лист на образец; в CSV — ZIP с файлом на образец (метаданные, результаты, все точки с пометкой «данные / обрезано») |

Кнопка **⬇ CSV** в заголовке секции графиков — выгрузка одного образца
без диалога.

### Графики — для публикаций

У каждого графика (в т.ч. миниатюры):

- **SVG** — настоящий вектор: правится в Inkscape/Illustrator,
  конвертируется в EPS/PDF для журналов;
- **PNG** — 600 dpi, для презентаций;
- **⧉** — PNG прямо в буфер обмена (вставка в PowerPoint/Word);
- **«Графики ZIP»** (островок сверху) — все графики всех активных
  образцов + сводные одним архивом SVG.

Имя файла содержит метку образца и тип графика (`метка_modulus.svg`).

## 8. Частые вопросы

**Метки образцов дублируются** — отредактируйте прямо в таблице; при
совпадении программа сама добавляет суффикс «·индекс».

**Участок выглядит странно на конкретном образце** — откройте график 4
и задайте границы вручную; авто-поиск можно ослабить/усилить через ⚙.

**Исключил образец — статистика не поменялась?** — меняется сразу;
строки «Среднее/СКО» внизу таблицы считаются только по активным.

**Почему ε_max и ε@σ_max разные?** — ε_max — деформация в конце
обрезанной кривой (момент разрыва), ε@σ_max — в точке максимальной силы;
в методичке определения «максимальной деформации» нет, поэтому выводим
обе.

**Всё сломалось / хочу начать заново** — кнопка **✕** в островке.
