# Instron Lab

Локальное приложение для пакетной обработки результатов испытаний
на одноосное растяжение — сырые CSV-файлы испытательной машины Instron
(`*.is_tens_RawData`).

- расчёт по методичке: ε, σ, σ_max, ε_max, ε@σ_max, E_тан, E_сек1/2,
  среднее и СКО по серии;
- графики по каждому образцу и сводные, подробный просмотр с зумом;
- ручная коррекция обрезки данных и линейного участка;
- исключение образцов из обработки одним кликом;
- экспорт таблиц (CSV / XLSX) и графиков для публикаций (SVG / PNG 600 dpi / ZIP).

Вся логика выполняется в браузере — сервер, Python и установка
зависимостей на рабочей машине не требуются.

📖 **Руководство пользователя:** [docs/USER_GUIDE.md](docs/USER_GUIDE.md)

## Запуск

| Вариант | Действие |
|---|---|
| Windows | `instron-lab.exe` — двойной клик, откроется окно приложения |
| Linux | `./instron-lab` |
| Без лаунчера | открыть `index.html` (single-file сборка) в любом браузере |

Лаунчер — ~7 МБ Go-бинарь: отдаёт встроенное приложение на
`127.0.0.1:<автопорт>`, открывает окно `msedge/chrome --app`
и завершается сам после закрытия окна.

## Структура репозитория

```
app/           фронт: React + TypeScript + Vite (вся логика: парсер, расчёты, экспорт)
app/testdata/  реальные сырые файлы — фикстуры для тестов
launcher/      Go-лаунчер (~140 строк, только stdlib)
build.sh       сборка всего: фронт → linux-бинарь + windows-exe
build.ps1      то же под Windows
.github/       CI: тесты + сборка артефактов/релизов
```

## Сборка

Требования: Node.js ≥ 18, Go ≥ 1.21 (только для лаунчера).

```bash
./build.sh        # фронт + launcher/instron-lab + launcher/instron-lab.exe
.\build.ps1       # Windows: фронт + launcher\instron-lab.exe
```

Только фронт: `cd app && npm ci && npx vite build` → `app/dist/index.html`
(один самодостаточный файл, открывается в браузере).

## Разработка

```bash
cd app
npm ci
npm run dev        # dev-сервер на :5173
npx vitest run     # 27 тестов: парсер, расчёты (сверка с реальными данными), xlsx
npx tsc --noEmit   # проверка типов
```

## Формат входных данных

Папка `*.is_tens_RawData/` с файлами `Specimen_RawData_N.csv`
(CP1251, `;`, десятичная запятая). Парсится по именам колонок, а не позициям;
геометрия и контрольный `Максимум Нагрузка` берутся из шапки.
Метки образцов подхватываются из соседнего `*.is_tens_Results.csv`,
если тот загружен вместе с данными.
